# Showcase View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gallery and List always side by side (the *Layout* option removed), the Default view renamed Showcase, and in Showcase a setup panel whose parts stay at fixed places: variants in a dropdown, the current livery large with arrows, a strip of small liveries, a one-row bottom with the sim's Configure tile reduced.

**Architecture:** The mod's aircraft-gallery feature loses its `layout` option and always mounts its livery column in Gallery and List; its `stock` view becomes `showcase`. The setup panel (`features/aircraft-setup`) keeps today's code path for Gallery and List (variants list, statistics, no liveries: `liveriesInGallery()` true) and gets a Showcase path (`liveriesInGallery()` false) laid out by a pure module of fixed places. Two helpers move to shared layers first (the dropdown list sizing to `sim/`, the wheel steps to `core/`) since features never import each other.

**Tech Stack:** TypeScript (ES2017, esbuild, node:test) in `mod/`; C# .NET 10 (MSTest) in `generator/`; Coherent GT in the sim.

**Spec:** [docs/superpowers/specs/2026-11-01-showcase-design.md](../specs/2026-11-01-showcase-design.md)

## Global Constraints

- The sim's own components for everything visible; the mod's SVG only for the heart and the eye (CLAUDE.md, Rules).
- Every sim component, attribute, state, child, manipulator API, `coui://` file and `TT:` key used is declared in `mod/compat.json`; the build refuses otherwise.
- Every change to the sim through a `Scope` (styles of sim elements restored on dispose); `inputLocker` / `data-input-group` on everything clickable.
- Layout passes every 250 ms write only on change (`setVariable`, `setStyle`); whole-pixel sizes, the last item of a row taking the rest.
- ES2017, no operator before `await`, no raw U+2028 / U+2029.
- A long list of the sim's tiles recycles a pool (`sim/component-pool.ts` `PooledCells`): never every livery alive.
- Each livery choice goes through `sim/configurator.ts` (`chooseLivery`, the configurator synced first); a variant through `chooseVariant`.
- Fixed places: for a given panel size, every part's top and height is the same whatever the aircraft, its variants and its liveries.
- Labels never shortened: if "Configure your aircraft", "Fuel and Payload", "Identification" or a view tab cannot show whole at a checked resolution, stop and ask the owner.
- If the sim has no fitting arrow icon for `IconButton_Squared`, stop and ask the owner.
- English everywhere in code, comments, logs, docs and commits; one commit per task.
- Commands: `cd mod; npm run check` (contracts, tsc, build, node:test); `dotnet build generator/MsfsUi.slnx`; `dotnet test generator/MsfsUi.slnx`; after a change of `mod/features.json`: `MSFS_UI_UPDATE_FIXTURES=1 dotnet test generator/MsfsUi.slnx`, then `npm run check`; in the sim: `& $dev install`, `& $dev reload`, `& $dev eval "…"` (`$dev = "generator\MsfsUi.DevTool\bin\Debug\net10.0-windows\msfs-ui-dev.exe"`).

## Review Focus

1. **An aircraft with one livery, or none readable**: both arrows disabled, the count "1 / 1" (or no count, no heart), the strip with one tile or empty, nothing thrown — tests in Task 5 (`LiveryStepper`) and a sim check in Task 6.
2. **Quick arrow clicks or wheel steps**: the livery shown is the one the sim ends on; a reload arriving between two steps does not snap the large livery back — tests in Task 5, measured in Task 6.
3. **Another aircraft chosen while a livery step is pending or the variant list is open**: the pending step is dropped (never sent to the new aircraft), the list closes or shows the new variants — test in Task 5, sim check in Task 6.
4. **A change of resolution (or of the left column's width) on Showcase**: the places, the open list's height and the moved Configure tile follow on the next pass — tests in Task 4 (places at three sizes), sim check in Task 8.
5. **Leaving the screen or unloading the mod**: the sim's Configure tile and statistics back as they were, on the career and company fleet screens too (they share `Fleet_Details`) — sim check in Task 6.
